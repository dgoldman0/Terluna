Milestone boundary

Implemented: immutable shared profiles, explicit upper extension, spectral first-order sky references, GPU/CPU frozen-field agreement, and a cloud-only multiple-scattering reference with analytic tests.

Still open: molecular multiple scattering and production integration; cloud grid and crop convergence; full production cloud-lighting calibration; interactive cache error; entraining mixed-phase cloud physics and conserved condensate.

The selected ozone, aerosol, vapor-absorption, phase-function and upper-temperature assumptions are experiments. Climate equilibrium and everyday weather frequencies are outside this checkpoint.

Source baseline: saved revision 04, built on 032765c5. The original shoreline HTML remains byte-identical to the audited draft. A1 uses locally generated data and performs no network requests. References and reproduction commands are in A1_METHODS.md.
