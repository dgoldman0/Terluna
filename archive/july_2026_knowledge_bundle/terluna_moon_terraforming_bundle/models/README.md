# Models

`terluna_screening_calculations.py` reproduces atmosphere mass, column mass, scale height, isothermal pressure and water-depth calculations.

The script is deliberately simple. It does not model:

- Variable gravity with altitude.
- Radiative transfer.
- Condensation or clouds.
- Atmospheric chemistry.
- Thermosphere or exosphere.
- Escape.
- Ocean or ice.
- Biology.

Use it as a unit-checked baseline before adding higher-fidelity models.
