# Lunashield-L1 — conversation recovery of the 2025 system dossier

**Status:** conversation-recovered technical record. The original 2025 file bytes have not been recovered. This document consolidates values preserved in the September 26–29, 2025 project conversations and the later recovery pass; it must not be represented as the original dossier text.

## Identified original artifact

The September 26, 2025 project conversation identifies an original work titled **“Lunashield-L1: System Design Dossier.”** The design was a plasma-inflated mini-magnetosphere at a lunar–solar L1-style location, intended for solar-wind / charged-particle protection. It was later separated from the EUV/X-ray photon-filter problem.

## Recovered system baseline

- Dual REBCO HTS seed coils.
- Coil radius: ~5 m; stack length: ~6 m.
- Seed field: ~0.05–0.1 T.
- Excitation: ~0.4–0.8 MA-turns.
- Operating temperature: ~30–50 K.
- Stored magnetic energy: order 10–50 MJ.
- Plasma sources: 6–12 helicon/ECR Ar/He injectors, ~5–50 kW each.
- Boost ion injection target: ~10^19–10^21 ions/s.
- Whistler / lower-hybrid RF current drive: ~0.2–1 MW typical, ~0.5–2 MW peak.
- Primary power: ~3–5 MWe fission + Brayton.
- Waste heat: ~8–12 MWth; radiator scale ~1,500–2,500 m².
- Electric propulsion: ~300–600 kWe.
- Dry mass: ~23–40 t; wet mass: ~25–46 t, depending configuration.
- Solar-wind pressure design range: ~1–10 nPa.
- Boundary-field target: ~70–150 nT.
- Nominal mature plasma standoff in the recovered concept: order 3–5 lunar radii.
- Argon hold/boost consumption in the historical notes: ~0.1–2 kg/day.
- Late-program target: ≥30% argon reclaimed / ISRU.
- Electric-propulsion propellant estimate in the historical program: ≤~100 kg/year.

The pressure-balance figure was explicitly framed as a solar-wind obstacle criterion, not a cosmic-ray dose criterion. The “few lunar radii” cavity was a design target, not a validated plasma solution.

## Staging idea recovered from later source tracing

The older concept was explicitly incremental: start with segmented magnetic seed stations and local cavities, add off-axis / Earth–Moon nodes, enlarge and overlap the cavities, fill gaps into a three-dimensional protected volume, then add redundancy so individual stations can be shut down. A later recovery record preserved the line: “You scale to a full-region shield by multiplying modules and widening/merging lobes until they overlap continuously.”

That staging logic remains potentially useful for experiments and local particle protection even though the plasma system cannot replace the physical photon filter.
