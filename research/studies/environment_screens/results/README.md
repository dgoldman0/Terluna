# Environment screening results

Generated by the study runner (then `research/run_environment_screens.py`; now `python -m research.studies.environment_screens.run --protection-archive ...`) from the documented original protection archive. See [findings](../../../findings.md), [source record](../sources.json) and [checks](../checks.json).

| File | Meaning |
|---|---|
| molecular_columns.csv | 232 solved or explicitly failed molecular boundary-value cases, approximation flags and residuals |
| molecular_profiles.json | Eight default-column profiles, compactly sampled for inspection |
| spectral_audit.json | Actual input ranges/hashes and integrated historical energy bounds for the unresolved response interval |
| historical_solar_bands.json | Five transcribed historical irradiance bands; response quantities intentionally null |
| band_heat_scenarios.csv | 27 explicitly assumed response combinations; excludes wavelengths above 118 nm and chemical closure |
| carbon_budget.csv | 180 fixed-biomass reserve/capacity cases; blank minimum capacity means negative cycle balance |
| oxygen_budget.csv | 20 periodic mixed-box cases with a finite oxygen ceiling and unmet demand |
| climate_budget.csv | 54 synthetic spatial thermal cases with residuals and freezing/extrapolation flags |
| climate_carbon_interface.csv | 18 examples using climate traces as input to hypothetical physiology |
| plume_heat_interface.csv | Eight imposed intercepted/thermalized fractions of inherited shield exhaust power |
| configurations.json | Default and swept parameters |
| summary.json | Counts, software versions and unestablished validation states |
| spatial_resolution.json | Separate coarse/fine-grid sensitivity; spatial convergence is not certified |
| test_output.txt | Actual output of 39 new consistency tests |

A periodic solution can have unmet biological demand or temperatures outside the chosen screen. Numerical convergence and conservation are reported independently from those consequences. None of these files supplies a total atmospheric lifetime, a solved filtered lunar climate or measured biological viability.
