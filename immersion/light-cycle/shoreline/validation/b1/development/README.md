# Development evidence

The first coast ended with positive-height edge vertices and exposed the sides
of the terrain volume. The early preview recorded 13 back-facing path failures.
The corrected coast tapers every boundary vertex below the sea-level sphere,
closing that boundary; the repeated preview had zero path failures.

These previews are superseded by the final B1 frame set. An early stochastic
camera/Sun term also produced large isolated samples. The final camera renderer
separates primary solar/specular terms into deterministic subpixel integration
and adds them after presentation filtering. Primary angular convergence remains
an explicit open gate; the selected vacuum disk check is a limited test.
